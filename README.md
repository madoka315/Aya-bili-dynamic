# Aya-bili-dynamic

B站 UP 主动态/开播实时推送插件，基于 HoshinoBot v2。**无需登录任何 B 站账号**。

## 特性

- **游客可用**：可选配置登录态增强稳定性
- **推送类型**：文字 / 图文 / 投稿视频 / 番剧影视 / 专栏 / 音频 / 转发 / 合集 / 课程 / 开播 / 直播推荐
- **分类型原生链接**：投稿直达视频页、专栏直达 cv 页、开播直达直播间
- **资源占用**：不做网页截图，资源占用极低

## 机制

伪装成未登录的安卓客户端，单次请求有一定成功率，本插件靠重试覆盖。若阿B未来收紧游客策略，在 config 填入 App `access_key` 即可携带登录态，无需改代码。

## 安装

1. 克隆本仓库到 `hoshino/modules/Aya-bili-dynamic`
2. 安装依赖（Python 3.8+）：
   ```bash
   pip install grpcio==1.54.0 protobuf==4.22.4
   ```
3. 在 `hoshino/config/__bot__.py` 的 `MODULES_ON` 中加入 `'Aya-bili-dynamic'`
4. 重启 bot，按需编辑插件目录下的 `config.py`

## 指令（群聊，群管理员/群主/超管可用）

| 指令                       | 说明                         |
| ------------------------ | -------------------------- |
| `关注动态 <UID> [关键词1/关键词2]` | 本群关注；有关键词则只推含关键词的动态        |
| `取关动态 <UID>`             | 取消本群关注                     |
| `动态关注列表`                 | 查看本群关注                     |
| `更新动态`                   | 立即检查本群所有关注                 |
| `测试动态`                   | 预览最新 2 条动态的真实渲染效果（不影响推送状态） |

## 配置（插件目录 `config.py`）

| 参数                                    | 默认            | 说明                             |
| ------------------------------------- | ------------- | ------------------------------ |
| `ACCESS_KEY`                          | `""`          | 可选，App 登录态                     |
| `POLL_INTERVAL`                       | `300`         | 成功拉取后的轮询间隔（秒）                  |
| `RETRY_INTERVAL`                      | `60`          | 被风控（空包）后的重试间隔（秒）               |
| `ERROR_BACKOFF`                       | `600`         | 接口报错退避（随连续失败倍增）                |
| `GATE_ALERT_N` / `GATE_ALERT_BACKOFF` | `20` / `1800` | 连续空包的告警阈值与长退避                  |
| `TICK_SECONDS`                        | `60`          | 心跳间隔                           |
| `MAX_POLLS_PER_TICK`                  | `2`           | 每次心跳最多轮询的 UID 数                |
| `TEXT_LIMIT`                          | `500`         | 展示正文最大字符数                      |
| `IMAGES_LIMIT`                        | `3`           | 每条动态最多推送的图片数                   |
| `DEFAULT_SUBS`                        | `{}`          | 默认订阅 `{群号: [UID, ...]}`，启动时加载的 |
| `PROXY`                               | `""`          | 可选代理                           |
